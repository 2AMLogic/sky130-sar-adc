## Scope statement

This record measures the front end ALONE at its own Csamp load. The combined front-end + CDAC-array load (`sim/sampling-cdac-handoff`'s question) needs a testbench instantiating two separate layout tops; `klt pex` extracts exactly one `--top` per run and swaps a single DUT `.include`, which is the multi-top gap 2AMLogic/klayout-tools#5494 tracks. The composed-block run additionally waits on issue #103's top-level LVS. Neither is a defect of this block's record; both are named so the numbers above are not over-read as composed-block behavior.
