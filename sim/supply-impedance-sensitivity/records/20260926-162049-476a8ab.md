## Findings

- **`ideal@fs_27c_1.80v` **reproduces**.** Re-running that point's own committed deck on this host at the pinned PDK commit gives mid-scale code **511**; record `20260926-050045-8e62675`'s committed log for the same point reports **511**.
- **`package-r-only@fs_27c_1.80v` **does NOT reproduce**.** Re-running that point's own committed deck on this host at the pinned PDK commit gives mid-scale code **511**; record `20260926-050045-8e62675`'s committed log for the same point reports **505**.
- **The mid-scale conversion's marginal decision is bit 9, at -0.0010 mV (-0.00028 LSB) of comparator input.** Every other traced decision of that conversion is further from its threshold (see the per-trial table). One LSB is 3.5156 mV at 1.8 V, and DR-004's own input-referred noise budget (Decision item 2; DR-004 is itself `proposed`, so that is a stated budget rather than a ratified line) is 1.0148 mV -- so that margin is not a 'code boundary' in the 1-LSB sense at all.
- **That marginal decision is the SIGN bit, and the sign bit cannot move the code by 1 LSB.** `DOUT9` gates all nine `SELn`/`SELp` pairs through `DOUT9N` (`design/sar_adc_top.spice`) and selects which side of mid-scale the remaining nine trials resolve, so a disturbance there re-runs the whole magnitude search rather than nudging one bit. A multi-LSB mid-scale code is the expected signature of a disturbed sign trial; a 1-LSB one is the lucky case.
- **Supply-unrelated perturbations move this code.** `ideal:vin+0.1lsb` reads 512 against its own arm's as-committed 511. None of these variants changes the supply network, a device or the netlist -- they change the input DC level by a fraction of an LSB, or only the solver's timestep sequence.
- **The off-boundary mid-scale inputs do not move at all, in any variant.** -0.25: [383]; +0.25: [641] across every variant of this probe (input fraction: the codes any variant produced). The sensitivity is a property of the `+0.00*V_REF` input, not of the deck, the arm or the perturbations.

- **What this probe does NOT establish.** It does not reconstruct the trajectory that produced the recorded 505: that run is not reproducible here, so its own per-trial margins cannot be read out after the fact. What would settle it is running this probe on a host where the mid-scale code does move -- the per-trial table then names the diverging trial directly.
