- It CAN say whether, at this stimulus and these network values, any captured code moves when the ideal supply sources are replaced by the package/substrate networks above, and how far each die node bounces.
- It CANNOT say what a real package or a real substrate does: the bond wire is one first-principles geometry (no mutual inductance between neighbouring wires, no package lead, no board), and `R_sub` is a single lumped resistor at two bracketing values, not an extracted substrate network.
