## Bare R_source budget for <= 1 provisional LSB of differential error, per corner

"Budget" is the largest swept R_source (ohm) at which `abs(diff_err_lsb) <= 1.0` still holds at that corner -- see `find_budget()` in this script. A budget equal to the largest swept value (100000 ohm) is right-censored: every swept value stayed under threshold, so the true budget is >= that value, not necessarily equal to it.

| `ss_27c_1.80v` | <= 10000 | <= 0 |
| `ff_27c_1.80v` | <= 10000 | <= 0 |
| `sf_27c_1.80v` | <= 100000 (right-censored) | <= 0 |
| `fs_27c_1.80v` | <= 0 | <= 0 |
| `tt_-40c_1.80v` | <= 100000 (right-censored) | <= 10000 |

## Result

- **Binding corner(s) (tightest 1-LSB budget): tied at `tt_27c_1.80v`, `fs_27c_1.80v`, `tt_125c_1.80v`, `tt_27c_1.62v`**, <= 0 ohm. Loosest corner(s): tied at `sf_27c_1.80v`, `tt_-40c_1.80v`, `tt_27c_1.98v`, <= 100000 ohm (right-censored). The tightest corner(s) allow **zero** margin for any nonzero drive impedance, while the loosest corner(s) allow up to <= 100000 ohm (right-censored) -- the bare R_source budget is **not** corner-invariant (a ratio is not meaningful when the tightest corner's own budget is zero).
- The `tt`/27C/1.8V point in this grid measures a 1-LSB budget of <= 0 ohm, consistent with (reproduces) the single-corner record's own finding for the same window/point.
- **This reveals the single-corner (tt/27C/1.8V) <= 0 ohm finding is itself corner-dependent, not a uniform floor**: 4 of 9 ratified corners (`tt_27c_1.80v`, `fs_27c_1.80v`, `tt_125c_1.80v`, `tt_27c_1.62v`) reproduce that same <= 0 ohm floor (zero margin for any nonzero drive impedance at those corners), but the remaining 5 corner(s) recover a positive budget, up to <= 100000 ohm (right-censored) at `sf_27c_1.80v`, `tt_-40c_1.80v`, `tt_27c_1.98v`. Any future on-chip VCM buffer / off-chip reference network sizing must still budget for the zero-margin corner(s) above, not the tt/27C/1.8V point alone -- the single-corner record's own scope note (single point, not yet corner-complete) was correct to flag this as unresolved.
- This campaign repeats ONLY the bare (undecoupled) R_source sweep at the legacy (400.0 ns) testbench convention window, at every ratified corner. The DR-006 worst-case (12 MHz, 83.333 ns) window and the C_decouple sweep remain single-corner (tt/27C/1.8V) only; a full-grid pass over either is a natural next step, same open-item shape as the other Section 7 Item 2 mechanisms before their own full-grid passes landed. It does not, on its own, establish what R_source/C_decouple an actual on-chip VCM buffer or off-chip reference network would present -- no such buffer exists in this design yet (docs/chipalooza/challenge-4-proposal.md Section 2.2).
